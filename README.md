# 대덕 활동강도 인덱스 (Daedeok Pizza Index)

펜타곤 피자 인덱스를 대덕연구개발특구에 이식한 개인 연구. 무료 공공데이터만 사용하고,
절대적 정확도보다 **동일 기관의 시계열 변동**과 **제도 캘린더와의 동기화**를 본다.

---

## 1. 개념설계

### 번역할 가정
원 모델의 핵심은 "조직 내부 활동 강도가 외부 소비 흔적으로 누출된다"이다.
대덕 버전에서 누출 경로는 소비가 아니라 **퇴근 시각**이다. 무료 데이터로 잡히는 건
카드 매출이 아니라 교통카드이기 때문이고, 이게 오히려 더 직접적이다.

- **Intensity(활동강도)** = 야간·주말 퇴근 흔적. 21시 이후 승차, 주말 승차.
- **Focus(집중도)** = 그 강도가 특정 시기에 몰리는 정도. 과제 종료월·평가·예산집행 마감과의 동기화.

최종 산출물은 "야근 지수"가 아니라 **기관 × 월 활동강도 시계열 × R&D 캘린더 교차**이다.

### 공간 단위 (노드)
전국 버스정류장 위치정보로 확정했다(`nodes.csv`, `match_stops.py`).
**전용 정류장이 있는 출연연은 9곳뿐이다.** 여기에 원자력안전기술원까지 10곳이 활성 노드다.

| 확정 | ETRI, 표준연, 화학연, 기계연, 생명연, 지질자원연, 항공우주연, 에너지연, 천문연, 원자력안전기술원 |
|---|---|
| **제외** | **원자력연(KAERI), 핵융합연(KFE), KISTI, 기초지원연(KBSI), 한의학연(KIOM)** — 대전에 이름이 붙은 정류장이 아예 없다 |

제외된 5곳은 단지 안쪽에 있어 통근버스·자가용으로만 접근하는 것으로 보인다.
이게 이슈 1(통근버스가 버스 데이터를 비운다)의 극단적 형태다. 신호가 약한 게 아니라 아예 없다.

정류장이 양방향 2개인 곳(표준연·기계연·항공우주연·천문연·KAIST)과 단방향 1개뿐인 곳
(ETRI·화학연·생명연·지질자원연·에너지연·원자력안전기술원)이 섞여 있다. 승차 총량을
그대로 비교하면 양방향 기관이 부풀려지므로, 지표는 반드시 비율(야간/전일)로만 쓴다.

**대조군 3종** — 신호는 항상 차분(difference)으로만 읽는다.
2026-01~07 실측으로 확정(`profile_metro.py`). **시청역은 대조군에서 뺀다** — 업무지구인데
야간승차 비율이 전 노선 1위(14.0%)라 둔산 유흥 상권이 섞여 있다. 업무 신호 대조군으로 쓰면 오염된다.

| 역할 | 역 | 근거 (아침하차% / 야간승차% / 주말·평일비) |
|---|---|---|
| 순수 업무지구 | **정부청사** | 28.3 / 6.6 / 0.51 — 교과서적 출퇴근 프로파일 |
| 상권·유흥 | **중앙로** | 10.1 / 13.6 / 1.13 — 주말이 평일보다 많음 |
| 대전 전체 baseline | 22개역 합계 | 계절·방학·연휴 공통 변동 제거 |

대학상권 대조군(궁동)은 **포기한다.** 유성온천역이 주말·평일비 0.77, 야간승차 7.5%로
상권 특성이 거의 안 잡힌다. 궁동 통행이 지하철을 안 탄다는 뜻이라 대조군 기능을 못 한다.

### 시간 단위
**양쪽 모두 일별 × 1시간.** 해상도가 맞는다.
- 도시철도(15060591): `일자 × 역 × 승하차 × 24시간대`
- 버스(15142057 API): `운행일자 × 정류장 × 시간대 × 이용자유형 × 승하차`

차분에 해상도 손실이 없다. 일 단위 이벤트 탐지가 설계대로 가능하다.

### 산식
기관 `i`, 월 `t`에 대해 원지표 `x`를 각각:

```
1. 원지표 계산      x_it
2. z-정규화         z_it = (x_it - mean_i(x)) / sd_i(x)     # 기관 내 정규화 (기관 간 규모 차 제거)
3. 대조군 차분      d_it = z_it - z_control,t
4. 단순 평균        Intensity_it = mean(d_it over 지표들)   # 가중치 추정 생략
```

원지표 목록:

| 코드 | 지표 | 출처 |
|---|---|---|
| N1 | 정문 정류장 21시 이후 승차 / 전일 승차 | 교통카드 빅데이터 |
| N2 | 주말 승차 / 평일 승차 | 교통카드 빅데이터 |
| N3 | 법정동 야간(20~24시) 유동인구 비중 | 유성구 유동인구 |
| N4 | ~~반경 500m 심야업종 점포 수~~ | **삭제.** 분모가 존재하지 않는다 (5장 참조) |
| N5 | ~~야간조도~~ | 삭제 (D 참조) |
| N6 | 기관 앞 대여소 심야(21시 이후) 대여 건수 | 타슈 대여이력 |

**Focus Score** = 이벤트 스터디. 과제 종료 집중월(6월·12월)과 예산집행 말기 전후 창에서
`Intensity`의 초과 반응 크기. 첫 결과물은 "마감 직전 달의 야간 승차가 평시 대비 몇 % 튀는가".

### 지하철의 역할 — 신호 아님, 기준선
대전 1호선(반석~판암)은 도룡·신성·가정동을 지나지 않는다. 출연연 접근역이 사실상 없다.
**실측으로 확증됨**: 연구단지 접점인 갑천역은 일평균 승차 1,102명으로 22개역 중 최하위다.
단지 접근 수요가 지하철을 사실상 안 탄다.
따라서 지하철은 **출연연 신호원이 아니라 대조군·정규화 기준선**으로 쓴다.
유성온천역 = 대학상권 대조, 시청·정부청사역 = 업무지구 대조, 전역 합계 = 대전 전체 야간활동 baseline.
대신 지하철 데이터는 시간대 해상도가 1시간이고 시계열이 길어서 기준선으로는 품질이 가장 좋다.

## 3. 이슈

**1. 통근버스·자가용이 버스 데이터를 비운다.**
출연연은 통근버스 비중이 높다. 기관 간 절대 비교는 의미 없고, **동일 기관의 시계열 변동만** 읽어야 한다.
인덱스를 기관 내 z-score로 정규화하는 이유가 이것이다.

**2. 구내식당 효과 → 실측으로 확인됨. 소비 기반 지표는 대덕에서 불가능하다.**
~~야근하면 외부 소비가 오히려 줄 수 있다~~ 는 가설이 아니라 사실이었다.
출연연 반경 500m 음식점이 2~45개뿐이고, 심야업종은 13개 노드를 통틀어 **1개**다.
그나마 잡히는 업종에 '구내식당·뷔페'가 ETRI·표준연·화학연·에너지연에서 직접 확인된다.

**야근해도 주변에 먹을 데가 없다.** 원 피자 인덱스의 전제가 여기서 깨진다.
신호원을 소비가 아니라 퇴근 시각으로 옮긴 1장의 판단이 결과적으로 옳았다.

**3. ~~해상도 불균형~~ — 해소됨.**
stcis 웹 포털은 전 지표군(IC01~IC05)에 시간대 차원이 없다. 요일 구분만 있고, 조회 기간 상한이
5~14일에 정류장은 단일 선택이라 대량 추출도 막혀 있다. 여기까지는 설계가 깨질 뻔했다.

그런데 **같은 교통카드 원천의 국토부 OpenAPI(15142057)에는 `tzon`(시간대) 필드가 있다.**
응답 항목: `opr_ymd`(운행일자) `dow_nm`(요일명) `emd_nm`(읍면동) `rte_nm`(노선) `sttn_nm`(정류장)
`sttn_seq`(정류장순서) `users_type_nm`(이용자유형) `tzon`(시간대) `ride_nope`(승차) `goff_nope`(하차).
읍면동 필터가 있어 유성구만 뽑을 수 있고, 이용자유형이 있어 **학생 통행을 분리**할 수도 있다
— 궁동 대학상권 오염 문제를 데이터 자체로 통제할 여지가 생긴다.

**4. 유동인구 데이터 단절.**
시간대 해상도가 있는 유성구 데이터는 2022에서 멈췄고, 최신 데이터는 시간대가 없다. N3는 과거 구간 보정용으로만.

**5. 상권 경계 ≠ 기관 반경.**
상권 매출·유동인구는 상권/행정동 경계로 집계되는데 이게 기관 반경과 안 맞는다. 좌표 기반 재집계 필수.

**6. 구조 변화 더미 필수.**
코로나(2020~22), 트램 공사에 따른 버스 노선 우회, 기관 이전·신축. 더미 없이 이벤트 스터디를 돌리면 전부 잡음.

**7. 해석의 근본 한계.**
활동강도↑가 연구 몰입인지 행정 부담(보고서 마감)인지 데이터는 구별하지 못한다.
개인 연구라 공표 리스크는 없지만, 결론을 쓸 때 이 구별 불가를 명시해야 한다.
오히려 후자로 읽으면("마감이 만드는 야근") 해석이 더 자연스럽다.

## 5. 1차 분석 결과 (지하철 한정, 2026-09)

`event_study.py`. 버스 API 대기 중이라 지하철만으로 돌렸다.
**기관 신호 검증이 아니라 방법 검증**이다. 지하철은 출연연에 닿지 않는다.

야간지표 = 21시 이후 승차 / 전일 승차, 평일·비공휴일만. 비율이라 역 규모에 영향받지 않는다.

### 양성 대조 — 지표는 작동한다
알려진 효과(대학 학기/방학)로 검출력을 먼저 확인했다. 학기(3·4월) vs 방학(1·2월):

| 역 | 차이 | 배수 |
|---|---|---|
| 중앙로 | **+1.67%p** | **4.1σ** |
| 정부청사 | −0.36%p | 2.7σ |
| 유성온천 | +0.06%p | 0.4σ |

중앙로에서 4.1σ로 잡힌다. **지표 자체에는 검출력이 있다.**
유성온천이 대학 방학조차 못 잡는 건 대조군 탈락 판단(3장)을 다시 확인해준다.

### 6월 마감 효과 — 검출 안 됨
전역 평균 6월 효과가 2024 +0.060%p, 2026 −0.013%p로 0에 붙어 있다.
역별 편차도 효과/SE 배수가 0.36~1.57에 그치고, **연도 간 부호 일관성이 22개 중 8개**로
우연 기대치(11개)보다 오히려 낮다. 노이즈다.

### 12월 — 상승은 있으나 마감이 아니다
전역 평균 +0.190%p로 6월의 3배다. 그런데 상위가 문제다.

```
중앙로 +0.864   월드컵경기장 +0.728   유성온천 +0.713   정부청사 +0.490
...
시청 −1.007 (최하위)
```

**상권·유흥 역이 상위를 쓸었고 업무지구인 시청이 꼴찌다.** 연말 회식·모임이지 마감 야근이 아니다.

### 결론 3줄
1. 지표는 실재 효과를 4σ로 잡는다. 방법 문제는 아니다.
2. 그럼에도 6월 마감 효과가 0이다. 지하철이 그 신호를 나르지 않는다는 뜻이고, 갑천역
   일평균 1,102명이라는 사실과 일치한다. **버스 데이터 없이는 진전이 없다.**
3. **12월 연말 효과는 앞으로 반드시 통제해야 할 교란요인이다.** 버스에서 12월에 출연연 앞
   야간 승차가 올라도 마감인지 회식인지 구별해야 한다. 중앙로 대조군이 그 역할을 한다.

### 상가 수집 결과 — N4 지표 폐기
소상공인 API 가 먼저 열려 `collect_stores.py` 로 13개 노드 반경 500m 를 훑었다.

| 노드 | 음식점 | 심야업종 |
|---|---|---|
| KIGAM / KARI / KINS / KRIBB | 2 / 3 / 2 / 3 | 0 |
| ETRI / 천문연 | 5 / 5 | 0 |
| 표준연 / 화학연 / 에너지연 | 11 / 16 / 18 | 0 |
| 기계연 / KAIST | 45 / 29 | 1 / 0 |
| **충남대 (대조군)** | **428** | **58 (13.6%)** |
| **정부청사 (대조군)** | **238** | **14 (5.9%)** |

출연연 13곳을 통틀어 심야업종이 **1개**다. 밀도를 잴 분모가 없다. **N4 는 폐기한다.**

대신 이 데이터는 통제변수로 남긴다. "외부 소비 기회가 애초에 없다"를 정량화한 값이고,
ETRI·표준연·화학연·에너지연에서 '구내식당·뷔페' 업종이 직접 잡히는 것이
이슈 2 의 실물 증거다. `data/stores_500m.csv` 2,086건.

### 타슈 결과 — 표본이 너무 작다
`tashu_aggregate.py`. 원본 zip 2.52GB(904만 행, 2024-08~2026-03)를 저장소에 넣지 않고
스트리밍 집계만 남겼다(`data/tashu_daily.csv` 6,174행).

**노드별 야간(21~24시) 대여 건수, 일평균**

| 노드 | 일평균 대여 | 야간 일평균 |
|---|---|---|
| 대조_충남대 | 305.7 | **35.1** |
| 연구단지운동장 / KRIBB / IBS | 20.1 / 21.1 / 17.0 | 2.3 / 2.0 / 1.9 |
| 연구단지네거리 / KIER / KRICT | 12.2 / 8.0 / 7.1 | 1.8 / 0.6 / 0.4 |
| ETRI / 천문연 / 한의학연 | 4.6 / 3.0 / 2.6 | 0.2 / 0.2 / 0.2 |

**출연연 야간 대여가 하루 0.2~2.3건이다.** 일별 분석은 불가능하고, 월 단위로 합쳐도
KRIBB·IBS·연구단지운동장 세 곳만 월 60~100건으로 겨우 경계에 걸린다(포아송 1σ가 8~10건).

게다가 계절성이 압도적이다. 겨울에 대여가 반토막 나고(충남대 야간 2025-09 1,607건 →
2026-01 504건) 야간 비율까지 함께 떨어진다. 마감 효과를 보려면 계절을 통제해야 하는데,
통제에 쓸 자유도가 표본에 남아 있지 않다.

**결론: 타슈는 주력 지표가 못 된다.** 버스가 열린 뒤 보조 확인용으로만 쓴다.
기대했던 "버스에 없는 한의학연구원 되살리기"도 야간 0.2건/일이라 실패다.

### 배포 데이터 오류 — 2025-12 결측, 2025-01 중복
`15137219` zip 안의 **`25년12월` 파일 내용이 2025-01 이다.** 행 수까지 203,545 로
`25년01월` 파일과 동일하다. 같은 파일이 두 번 들어갔다.

따라서 **2025년 12월 데이터는 배포본에 존재하지 않고**, 그대로 집계하면 2025-01 이
두 배로 잡힌다. `tashu_aggregate.py` 는 파일명이 아니라 첫 행의 실제 연월로 중복을
판정해 건너뛴다. 12월 마감 분석에 쓸 수 있는 건 2024-12 한 번뿐이다.

### 유료 데이터 구매 판단
**카드매출 데이터는 사지 않는다.** 보류가 아니라 기각이다.
반경 500m 에 음식점이 2~5개인 곳에서 행정동 단위 카드매출을 사봐야 출연연 신호가 아니라
주변 주거지 소비를 사는 것이다. 1순위로 꼽았던 KDX 행정동×시간대 카드매출이 여기서 탈락한다.

유동인구(지오비전 등)는 살아 있다. 소비가 아니라 체류를 재기 때문이다. 다만 이것도
버스 데이터로 신호를 먼저 확인한 뒤로 미룬다.
